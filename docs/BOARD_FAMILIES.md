# Board families

Generated by `tools/board_families.py` from MAME 0.251's driver data. A family is a MAME driver source file: every game on that hardware. A game in a family with a **kit** can be put on the AI with `tools/new_game.py`; the others need the family's decoder written first (the first game), after which its siblings cost far less.
